# Лабораторная 13

- `GraphA`: алгоритм Кана, очередь с приоритетом выбирает лексикографически минимальную доступную вершину.
- `GraphB`: цикл существует, если алгоритм Кана не смог обработать все вершины.
- `GraphC`: два итеративных обхода Косарайю; компоненты выводятся в топологическом порядке графа конденсации, вершины внутри компоненты сортируются.

Общий парсер принимает рёбра `A -> B, B -> C`, допускает пробелы, петли и повторные рёбра.
Повторные рёбра учитываются один раз. Пустой граф допустим.
`GraphA` отвергает циклический граф, некорректные рёбра вызывают `IllegalArgumentException`.
Обходы не используют рекурсию. Сортировка обеспечивает стабильный порядок вывода.

Из корня репозитория с JDK 25:

```bash
mkdir -p /tmp/romanovich-labs
javac -encoding UTF-8 -cp init.jar -d /tmp/romanovich-labs src/by/it/group551001/romanovich/lesson13/*.java
java -cp /tmp/romanovich-labs:init.jar org.junit.runner.JUnitCore by.it.group551001.romanovich.lesson13.Test_Part2_Lesson13 by.it.group551001.romanovich.lesson13.Lesson13RegressionTest
printf 'A -> B, A -> C, B -> D, C -> D\n' | java -cp /tmp/romanovich-labs by.it.group551001.romanovich.lesson13.GraphA
```

В тестах консольных программ 20 примеров для A, 12 для B, 8 для C.
Дополнительно компоненты проверяются на случайных графах через независимое вычисление достижимости,
а все три алгоритма проходят проверку на цепочке из 15001 вершины.
