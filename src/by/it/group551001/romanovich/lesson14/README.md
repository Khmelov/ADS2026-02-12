# Лабораторная 14

Общая DSU хранит массивы родителей и размеров компонент. `find` сжимает путь,
`union` присоединяет меньшую компоненту к большей.

- `PointsA`: проверяет пары трёхмерных точек и объединяет их при расстоянии строго меньше D; сложность O(N² α(N)). Разность координат вычисляется без переполнения int.
- `SitesB`: сопоставляет именам сайтов номера и объединяет связанные сайты, включая петли и повторные пары; операции DSU имеют амортизированную сложность O(α(N)).
- `StatesHanoiTowerC`: выполняет оптимальное решение Ханойской башни и объединяет состояния с одинаковой максимальной высотой стержней. Начальное состояние не учитывается. Коллекции не используются; время и память O(2^N), глубина рекурсии O(N).

По тестам преподавателя точки и сайты выводятся по убыванию размеров групп,
Ханой — по возрастанию. В текстах TaskA/TaskB встречается противоречивое указание порядка.
При D=0 точки не объединяются, даже если совпадают. Пустой набор выводит пустую строку.
Для Ханоя допустимы N от 0 до 30 по ограничению индексации массивов;
практический предел ниже и зависит от памяти, N=21 проверяется тестом преподавателя.

Из корня репозитория с JDK 25:

```bash
mkdir -p /tmp/romanovich-labs
javac -encoding UTF-8 -cp init.jar -d /tmp/romanovich-labs src/by/it/group551001/romanovich/lesson14/*.java
java -cp /tmp/romanovich-labs:init.jar org.junit.runner.JUnitCore by.it.group551001.romanovich.lesson14.Test_Part2_Lesson14 by.it.group551001.romanovich.lesson14.Lesson14RegressionTest
printf '5\n' | java -cp /tmp/romanovich-labs by.it.group551001.romanovich.lesson14.StatesHanoiTowerC
```

Дополнительные проверки покрывают границу расстояния, совпадающие точки,
транзитивность объединения, крайние координаты int, повторы сайтов и рост DSU.
Состояния Ханоя сравниваются с независимой формулой положения каждого диска.
